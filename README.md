# Blinkit Sales Dashboard

An interactive Power BI dashboard that analyses grocery sales across outlets, item categories and locations.

**[View the live dashboard](https://YOUR-USERNAME.github.io/blinkit-dashboard/)** (replace with your GitHub Pages link)

![Dashboard preview](images/dashboard.png)

## What it shows

**KPI cards**
- Total Sales
- Average Sales
- Number of Items
- Average Rating

**Charts**
- Total Sales by Item Type (bar)
- Total Sales by Item Fat Content and Outlet Location Type (bar)
- Total Sales by Outlet Establishment Year (line)
- Sales share by Item Fat Content (donut)
- Sales split by Outlet Size and Item Fat Content (donut)
- Sales by Outlet Location Type (funnel)
- Outlet Type summary with sales, average sales, items, ratings and item visibility (table)

**Filters (slicers)**
- Outlet Size
- Outlet Location Type
- Item Type
- Metric selector

## How to use

1. Download `blinkit_dashboard.pbix`.
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Use the slicers to filter the charts.

Or open the live dashboard link above, which needs no installation.
