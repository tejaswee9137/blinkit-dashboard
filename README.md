# Blinkit Sales Dashboard

A Power BI dashboard that analyses grocery sales across outlets, item categories and locations.

![Dashboard overview](images/dashboard.png)

## What it shows

**KPI cards**
- Total Sales
- Average Sales
- Number of Items
- Average Rating

**Charts**
- Total Sales by Item Type (bar)
- Total Sales by Item Fat Content and Outlet Location Type (bar)
- Total Sales by Outlet Establishment Year (line)
- Sales share by Item Fat Content (donut)
- Sales split by Outlet Size and Item Fat Content (donut)
- Sales by Outlet Location Type (funnel)
- Outlet Type summary with sales, average sales, items, ratings and item visibility (table)

**Filters (slicers)**
- Outlet Size
- Outlet Location Type
- Item Type
- Metric selector

## How to open the dashboard

1. Click `blinkit_dashboard.pbix` above, then click **Download raw file** (the download icon at the top right).
2. Open the file in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows only).
3. Click the slicers to filter the charts.
